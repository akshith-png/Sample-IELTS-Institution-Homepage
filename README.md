# IELTS Institute Homepage 🎓

A modern, responsive ReactJS homepage for a fictional IELTS coaching institute.  
Built with React + Tailwind CSS, following clean component architecture and mobile‑first design principles.

---

## 🚀 Tech Stack
- React 18 – Component-based UI  
- Tailwind CSS 3 – Utility-first styling, responsive by default  
- PostCSS + Autoprefixer – Cross-browser compatibility  
- CRA (Create React App) – Quick bootstrapping  

---

## 📂 Project Structure
src/  
├── components/  
│   ├── Navbar.jsx  
│   ├── Hero.jsx  
│   ├── Features.jsx  
│   ├── Testimonials.jsx  
│   └── Footer.jsx  
├── App.jsx  
├── index.css  
└── index.js  

- Separation of concerns: Each section is a self-contained component  
- Scalable: Easy to extend with new sections or pages  
- Minimal boilerplate: Removed unused CRA defaults for clarity  

---

## 🖥️ Features
- Responsive Navbar with mobile hamburger menu  
- Hero Section with headline, subtext, CTA, and banner image  
- Feature Cards (Speaking Practice, Mock Tests, AI Band Score, Coaching)  
- Student Testimonials with reviews and ratings  
- Footer with quick links and contact info  

---

## 📱 Responsiveness
- Mobile-first design  
- Tested on common breakpoints (sm, md, lg)  
- Flexbox + Grid for adaptive layouts

## ⚡ Setup Instructions
Clone the repo and run locally:

git clone https://github.com/<your-username>/ielts-institute-homepage.git  
cd ielts-institute-homepage  
npm install  
npm start  

The app will be available at http://localhost:3000
